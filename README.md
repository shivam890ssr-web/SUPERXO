# SuperXO

SuperXO is a modern web-based Tic-Tac-Toe game designed with an attractive and interactive user interface.

## Features

- 🎮 Interactive Tic-Tac-Toe gameplay
- 👥 Two-player mode
- 📱 Responsive design
- 🎨 Modern and user-friendly UI
- 🏆 Win and draw detection
- 🔄 Restart/New Game functionality
- ⚡ Fast and lightweight

## Technologies Used

- HTML5
- CSS3
- JavaScript
